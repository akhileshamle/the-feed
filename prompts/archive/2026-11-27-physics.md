PHYSICS-MAXING CHEAT SHEET (starter)
Goal: sharper thinking, pattern recognition, decision making. One concept a day, ~5 min.

CORE CONCEPTS
1. Fermi estimation: N = a x b x c ... -> size a problem to the nearest order of magnitude
2. Dimensional analysis: [LHS] = [RHS] -> sanity-check any claim by its units
3. Conservation laws: E_in = E_out + dE_stored -> ask "where did it go?" (time, money, attention)
4. Newton's 2nd law: F = ma -> find the force and the inertia in any change
5. Feedback loops: dx/dt = kx -> k>0 compounds, k<0 stabilizes
6. Entropy: dS >= 0 -> order decays unless you spend energy on maintenance
7. Equilibrium/stability: d2U/dx2 > 0 -> stable; is this routine robust or fragile?
8. Signal vs noise: sigma_mean = sigma/sqrt(N) -> average before judging a data point

BONUS LENSES
- First principles: strip assumptions, rebuild from basics
- Right model: what can I safely ignore?
- Bottleneck: what is the limiting factor?
- Scaling: area ~ L^2, volume ~ L^3
- Uncertainty: use ranges, not false precision

DECISION CHECKLIST
1. Estimate (Fermi)  2. Check (units/sanity)  3. Trace (conservation)  4. Model (feedback/equilibrium)  5. Test (signal vs noise)
